FakeAuthenticator

class FakeAuthenticator(val origin: String, random: Random = Random.Default)

In-memory platform authenticator producing cryptographically valid WebAuthn responses (ES256, attestation "none"), so they pass real server verifiers.

Like a platform authenticator it checks the options' RP ID against origin: an http(s) origin's host must equal the RP ID or be a subdomain of it (otherwise PasskeyError.Misconfigured); for other origins (e.g. Android android:apk-key-hash:...) the options must name the RP ID explicitly (otherwise PasskeyError.InvalidOptions).

Safe to call from concurrent coroutines: every operation runs under one lock.

Extensions: prf and largeBlob are supported (toggle with prfSupported / largeBlobSupported); outputs appear in clientExtensionResults as on real platforms. PRF is deterministic and test-only: HMAC-SHA256(secret, SHA-256("WebAuthn PRF" || 0x00 || salt)), mirroring the WebAuthn salt hashing, where secret is derived from the credential id (so it is predictable; never use this as real key material). The same passkey and salt always give the same 32 bytes; different salts or passkeys give different ones. Large blobs are kept in memory per passkey (FakeCredential.largeBlob).
