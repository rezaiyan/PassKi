FakePasskeys

class FakePasskeys(origin: String, random: Random = Random.Default) : Passkeys

Drop-in Passkeys for unit tests: real WebAuthn responses, no device.

Behaves like a platform implementation: operations fail with PasskeyError.NotSupported when the matching capability flag is off, signals validate and compare ids by their bytes, and the RP ID is checked against origin (see FakeAuthenticator).

Operations are safe to call from concurrent coroutines. The public mutable collections savedPasswords and receivedSignals are not synchronised: mutate or inspect them from test code before or after calls, not concurrently with them.

Logs like the platform implementations do, through com.alirezaiyan.passki.PassKi.logHandler, so a test can assert what your app's users would see in logcat. A test that changes PassKi.logLevel or PassKi.logHandler should restore them in @AfterTest: they are process-wide.

Parameters

origin

the web origin written into clientDataJSON, e.g. https://example.com.

random

source for credential ids; pass a seeded Random for deterministic ids.

Samples

runTest {
        val device = FakePasskeys(origin = "https://example.com") // your server's allowed origin
        val created = device.register(TestOptions.creation("example.com")).getOrThrow()
        // send created.json to your server's verifier here
        val assertion = device.signIn(TestOptions.request("example.com")).getOrThrow()
        assertEquals(created.credentialId, assertion.credentialId)
    }
