Interrupted

data object Interrupted : PasskeyError

The request didn't run to the end, and nothing is wrong with it: the system interrupted it (e.g. the app went to the background), or another PassKi passkey request was still showing (only one runs at a time). Safe to retry; don't show it to users as a failure.
