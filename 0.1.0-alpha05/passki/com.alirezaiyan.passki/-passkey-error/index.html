PasskeyError

sealed class PasskeyError

Every way a passkey operation can fail, across all platforms. fixHint is non-null when a developer can fix the cause (configuration, options). checkId names the setup check from the PassKi check catalog that covers the cause, the same ID PasskeyDoctor, ./gradlew passkiCheck and the web verifier report, and docsUrl links its docs page.

Open: new subtypes may be added in minor releases; keep an else branch in exhaustive whens.
