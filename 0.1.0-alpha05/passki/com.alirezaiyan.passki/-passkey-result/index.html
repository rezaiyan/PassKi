PasskeyResult

sealed interface PasskeyResult<out T>

Outcome of a passkey operation: either Success with a value or Failure with a typed PasskeyError.

Closed: it is always one of these two; a when over it needs no else branch.

Samples

passkeys.signIn(server.authenticationOptions()).fold(
        onSuccess = { server.finishSignIn(it.json); SignInState.SignedIn },
        onFailure = { if (it.isUserCancellation) SignInState.Idle else SignInState.Failed(it.message) },
    )
