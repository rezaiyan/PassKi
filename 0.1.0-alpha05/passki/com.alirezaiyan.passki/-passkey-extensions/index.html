PasskeyExtensions

object PasskeyExtensions

Adds typed WebAuthn extensions to the options JSON your server produced, before you pass it to Passkeys.register or Passkeys.signIn. Read the outputs from PasskeyRegistration / PasskeyAssertion.

Usually your server adds extensions itself; use these helpers when the extension inputs are produced on the device (e.g. a PRF salt for client-side encryption that the server must never see).

Every helper returns new JSON: other extensions and fields are preserved, as is a {"publicKey": ...} envelope. They throw IllegalArgumentException if the JSON is not an options object, or is the wrong kind (creation options have rp / user; request options do not).

Extensions are best-effort, as in browsers: a provider or OS that does not support one ignores it, and its output is then null. PRF needs iOS 18+ (Android: provider-dependent, Google Password Manager supports it); largeBlob needs iOS 17+.
