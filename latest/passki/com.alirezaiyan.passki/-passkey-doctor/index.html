passki/com.alirezaiyan.passki/PasskeyDoctor

PasskeyDoctor

actual object PasskeyDoctor

Diagnoses passkey setup for a relying party on this device: platform support, app configuration and the well-known association files (assetlinks.json on Android, apple-app-site-association on iOS).

Use it in debug builds only: it performs network requests.

val report = PasskeyDoctor.run("example.com")
if (report.failures.isNotEmpty() || report.warnings.isNotEmpty()) println(report)
Content copied to clipboard

Supported on Android and iOS. On other platforms the report holds a single DoctorStatus.Skipped check.

actual suspend fun run(rpId: String): DoctorReport

Runs every check for rpId (a bare domain such as example.com, no scheme or path) and returns the results. Never throws for setup problems; they are reported as checks.
