PasskiDemoServer

class PasskiDemoServer

Client for the hosted PassKi demo relying party, so you can try passkeys in your app before you have a domain or a WebAuthn server. For evaluation only: demo users expire after 24 hours and the domain is shared.

The server creates every challenge and verifies every response with SimpleWebAuthn. This class only moves JSON between it and PassKi, exactly as your own server API would:

val demo = PasskiDemoServer()
passkeys.register(demo.registrationOptions("alice"))
    .onSuccess { println(demo.verifyRegistration(it.json)) } // "verified by server ✓ signCount 0 …"
passkeys.signIn(demo.authenticationOptions())
    .onSuccess { println(demo.verifyAuthentication(it.json)) }

The app must be associated with RP_ID: apply the Gradle plugin with passki { useDemoServer() } and run ./gradlew passkiSetup, which registers your package, signing key and iOS app ID with the demo server.

Every call throws DemoServerException when the server is unreachable or answers with an error.
